# Primary source research register
Checked through 13 September 2026 via public web research. This verifies source purpose, not future availability, API entitlement, complete market coverage or a live stock dataset. Refresh before each run. Summaries below are brief; documents are linked rather than reproduced.

| ID | Official source | Use and researched finding |
|---|---|---|
| S01 | [NSE corporate filings](https://www.nseindia.com/companies-listing/corporate-filings-application) | Financial results, announcements, actions and shareholding disclosure discovery |
| S02 | [NSE announcements](https://www.nseindia.com/companies-listing/corporate-filings-announcements) | Material issuer announcements and updates |
| S03 | [SEBI corporate filing source directory](https://www.sebi.gov.in/curation/corporate_filings.html) | Points to NSE and BSE financial disclosure routes |
| S04 | [NSE market reports](https://www.nseindia.com/all-reports) | Daily/historical reports, bhavcopy and index total-return data |
| S05 | [NSE ASM](https://www.nseindia.com/static/regulations/additional-surveillance-measure) | Enhanced surveillance framework, restrictions need security-specific refresh |
| S06 | [NSE GSM](https://www.nseindia.com/static/regulations/graded-surveillance-measure) | Stage-dependent trading and deposit constraints |
| S07 | [RBI data releases](https://statistics.rbi.org.in/) | Official monetary and macroeconomic series |
| S08 | [Nifty200 Momentum 30](https://niftyindices.com/indices/equity/strategy-indices/nifty200-momentum-30) | Uses 6/12-month returns adjusted for volatility; supports investigating momentum, not proof of this workflow's swing rules |
| S09 | [Nifty200 Quality 30](https://niftyindices.com/indices/equity/strategy-indices/nifty200-quality-30) | Quality construction considers ROE, debt/equity and five-year EPS variability; not a substitute for sector diligence |
| S10 | [NSE Indices methodology](https://www.niftyindices.com/resources/index-methodology) | Current authoritative methodology documents for benchmark definitions |
| S11 | [SEBI 2024 derivatives study](https://www.sebi.gov.in/media-and-notifications/press-releases/sep-2024/updated-sebi-study-reveals-93-of-individual-traders-incurred-losses-in-equity-fando-between-fy22-and-fy24-aggregate-losses-exceed-1-8-lakh-crores-over-three-years_86906.html) | Historical FY22–FY24 retail-loss evidence; not presented as the latest study |
| S12 | [SEBI investor fraud guidance](https://investor.sebi.gov.in/spot-any-scam.html) | Guaranteed high-return promises are warning signs |
| S13 | [CBDT sale of shares](https://www.incometaxindia.gov.in/en/sale-of-shares) | Conditions and reference tax rates; current-law checks remain necessary |
| S14 | [CBDT Schedule 112A](https://www.incometaxindia.gov.in/w/schedule_112_a) | Annual exemption and LTCG reference; eligibility and cess/surcharge matter |
| S15 | [Kite historical API docs](https://kite.trade/docs/connect/v3/historical/) | Authorized historical candles; documentation is not account access |
| S16 | [Kite quote docs](https://kite.trade/docs/connect/v3/market-quotes/) | Quote and instrument interface; confirm current subscriptions and timestamps |
| S17 | [NSE insider-trading filings](https://www.nseindia.com/companies-listing/corporate-filings-insider-trading) | Exchange route for disclosed insider transactions; transaction type and date require inspection |
| S18 | [NSE bulk and block deals](https://www.nseindia.com/report-detail/display-bulk-and-block-deals) | Large transaction records; a deal does not prove a continuing holding or investor rationale |
| S19 | [SEBI PIT Regulations](https://www.sebi.gov.in/legal/regulations/mar-2025/securities-and-exchange-board-of-india-prohibition-of-insider-trading-regulations-2015-last-amended-on-march-12-2025-_92672.html) | Regulatory context for insider trading and disclosures; refresh amendments before legal conclusions |
| S20 | [AMFI scheme-wise disclosures](https://www.amfiindia.com/otherdata/scheme-wise-disclosure) | Route to mutual-fund scheme disclosures; reconcile scheme, month and security identity |
| S21 | [Piotroski 2000 paper record](https://www.jstor.org/stable/2672906) | Original F-score research context was high book-to-market firms; historical evidence is not a current India-wide performance guarantee |
| S22 | [Beneish 1999 paper](https://www.calctopia.com/papers/beneish1999.pdf) | Original eight-variable manipulation-detection model and limitations; a flag is not a fraud finding |
| S23 | [Altman 1968 paper record](https://onlinelibrary.wiley.com/doi/10.1111/j.1540-6261.1968.tb00843.x) | Original discriminant model for financial distress; model form and sample limit generalization |
| S24 | [NSE corporate announcements/XBRL](https://www.nseindia.com/companies-listing/corporate-filings-announcements) | Displays exchange broadcast, received and dissemination times and provides downloadable announcement data; use timestamps for availability, and inspect attachments/corrections |
| S25 | [NSE India VIX](https://www.nseindia.com/static/products-services/indices-indiavix-index) | Option-implied expected volatility over the next 30 calendar days; it is not a direction forecast |
| S26 | [NSE FPI/DII activity](https://www.nseindia.com/reports/fii-dii) | Aggregate institutional activity for market context, not proof of causation for an individual security |
| S27 | [NSE equity-index methodology](https://niftyindices.com/Methodology/Method_NIFTY_Equity_Indices.pdf) | Primary methodology reference for factor construction and normalization; copy only the applicable current method and preserve its date |
| S28 | [Daniel, Sornette and Wohrmann on look-ahead benchmark bias](https://arxiv.org/abs/0810.1922) | Demonstrates that using future benchmark constituents can materially bias performance evaluation; supports historical membership controls |
| S29 | [BSE corporate announcements](https://www.bseindia.com/corporates) | Alternate official route for issuer announcements, results, insider disclosures and shareholding records; reconcile later amendments |
| S30 | [NSE ASM reports](https://www.nseindia.com/reports/asm) and [GSM reports](https://www.nseindia.com/reports/gsm) | Security-level surveillance status for current exit-risk checks; status can change and must be refreshed |
| S31 | [NSE historical India VIX](https://www.nseindia.com/reports-indices-historical-vix) | Historical option-implied market-volatility context; India VIX is not a direction or single-stock forecast |

The scoring weights, risk defaults and technical trigger examples are workflow design choices. Official index descriptions do not validate individual stock recommendations. Do not invent a paid terminal, expert consultation or predictive edge from these sources.
