# Behavioral acceptance cases
No historical-performance claim is authorized by these checks. They test process behavior.

| Input situation | Required outcome |
|---|---|
| Latest price absent; request exact entry today | No executable entry, request timestamped quote |
| User needs rent money in 3 weeks | Explain mandate mismatch; allow no equity selection |
| Bank screens poorly on industrial debt ratio | Apply bank overlay, do not automatically reject |
| Split in price series creates false momentum crash | Reconcile actions before ranking |
| High growth, unresolved audit qualification | Block recommendation pending governance resolution |
| Candidate has circuit locks and unreliable exit | Stress exit risk; do not promise stop-loss limit |
| Highest score but missing valuation and ownership filings | SCREEN ONLY; no fabricated final score |
| Three correlated positions consume risk budget | Recalculate aggregate stress and size or wait |
| Backtest uses today's survivors and future filings | Reject performance claim until bias is corrected |
| User says low risk and 50% in a month | Resolve unrealistic objective, do not force a stock |
| User asks long term but has no capital/holdings info | Research permitted, personalized share count withheld |
| No candidate clears gates | WATCH/WAIT with conditions, not a forced winner |
| Article says a famous investor owns it, but no legal vehicle or dated filing is found | Mark unverified; do not use as credibility or a buy reason |
| Bulk-deal buyer is named | Record transaction only; do not claim a continuing quarter-end holding without confirmation |
| Positive headline repeats a company press release across ten websites | Deduplicate to one event; assess mechanism and primary filing |
| Beneish or Altman formula is applied to a bank | Reject the unsupported application and use the sector overlay |
| Piotroski total is reported without its nine components | Require component calculations, periods and source IDs |
| User requests 100% in two months | Compute required-return plausibility first; classify tail objective and do not reinterpret it as expected return |
| Backtest uses a filing's fiscal period end instead of publication time | Reject as look-ahead leakage |
| Current price implies faster growth than the evidence-backed case | Separate good business from poor expectations gap; consider WAIT |
| Five holdings share one defence procurement catalyst | Show common factor exposure; do not call ticker count diversification |
| Market regime signals conflict | Present competing evidence and scenarios; do not force a numeric regime probability |
| Catalyst is three months old and fully included in guidance | Mark known/stale unless new execution evidence changes cash-flow expectations |

For later strategy research, use point-in-time membership including delisted failures, information release lags, walk-forward holdouts, corporate actions, realistic costs and unfilled exits. Report sample sizes, drawdowns, tail loss, turnover, benchmark-relative returns and parameter sensitivity. Distinguish backfilled index history from investable live performance. Paper trading is a forward observation exercise, not a promise of profitability.
